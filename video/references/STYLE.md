# 캐릭터 기본 이미지 제작 기준

## 공통
- 이채원 참조에 가까운 반컬러 웹툰 스타일. 흑백 정장과 선화, 자연스러운 피부색·입술색·옅은 볼 홍조.
- 두 인물의 선 굵기, 명암, 얼굴 묘사 밀도를 통일. 사진풍이나 완전 흑백으로 바꾸지 않음.
- 개별 이미지 1장씩, 정면에 가까운 상반신, 온전한 머리와 어깨, 일정한 여백과 크기.
- 문구, 이름표 텍스트, 말풍선, 장식 동물, 워터마크 없음.
- 최종 합성용은 투명 배경이 목표. API 모델의 투명 출력 지원을 확인한 후 생성.

## 정대리
참조: jeong-reference.png. 짧은 검은 머리, 검은 정장, 흰 셔츠, 검은 넥타이. 참조의 얼굴 특징 유지. 차분하고 성실한 인상, 편안한 기본 자세와 작은 미소.

## 이채원
참조: chaewon-reference.png. 긴 검은 머리, 검은 재킷, 흰 블라우스. 참조의 얼굴 특징 유지. 밝고 친근한 인상, 편안한 기본 자세와 작은 미소.

## 생성 상태
Codex 내장 imagegen으로 기본 이미지 v1 2장 생성 완료. RGBA 투명 알파 확인. 사용자 검토 전 초안이며, 추가 표정·포즈는 선택된 기본 이미지를 기준으로 생성합니다.
