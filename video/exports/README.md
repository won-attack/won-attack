# 팀 공유용 최종 시연 영상

최종 MP4는 로컬에 보관하며 Git에는 포함하지 않습니다. 팀 공유는 별도 파일 전달로 진행합니다. 저장소를 clone/pull한 팀원은 제작 코드를 실행해 재생성하거나 완성 파일을 별도로 받아야 합니다.

| 파일 | 기업·진행자 | 규격 |
|---|---|---|
| `hynix-30s-v2.mp4` | SK하이닉스 · 이채원 | 쇼츠 1080×1920, 30초 |
| `samsung-30s-landscape-v1.mp4` | 삼성전자 · 정대리 | 가로 1920×1080, 30초 |
| `hyundai-30s-landscape-v1.mp4` | 현대차 · 이채원 | 가로 1920×1080, 30초 |

세 파일 모두 H.264/AAC, 30fps입니다. 영상 검증 시연을 위해 의도적인 오류·과장 표현이 들어 있습니다. 음성은 macOS 로컬 합성 음성이며 CLOVA 더빙은 아직 적용하지 않았습니다.

`manifest.json`에 파일 크기와 SHA-256을 기록했습니다. 재생성 결과는 `../out/`에 생깁니다. 최종본을 갱신할 때 로컬 파일과 매니페스트를 함께 갱신하세요. MP4는 .gitignore로 제외됩니다. `out/`의 임시 출력과 `node_modules/`, `.cache/`, `.env`는 커밋하지 않습니다.
