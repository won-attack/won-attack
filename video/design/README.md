# 화면 시안 v1

`preview.html`은 이미지가 내장된 독립 HTML입니다. 브리핑형과 대화형 1080×1920 정지 화면 시안, 작업 여백 토글을 포함합니다. 편집 가능한 독립 SVG 2개와 design-tokens.json도 있습니다.

- A: 이채원 1명 + 스튜디오 + 상단 숫자 카드 + 하단 2줄 자막
- B: 정대리/이채원 2명 + 사무실 + 말풍선 + 하단 강조 자막
- 짙은 남색 #11283f, 청록 #1f756d, 밝은 민트 #e5f2ee
- 제목 62px, 자막 46~51px, 고지 25px. 한국어 시스템 폰트를 사용하므로 기기에 따라 표현이 달라질 수 있습니다.
- 주요 콘텐츠 좌우 여백 64px, 상단 112px. 업로드 플랫폼 UI 안전 영역은 추후 영상 샘플에서 검수합니다.
- 모든 문구는 배치 확인용 임시 문장입니다. 최종 금융 주장이나 판정은 넣지 않았습니다.
- 생성형 이미지는 배경 원본과 캐릭터만이며 글자/카드는 SVG 코드 레이어입니다.
- 브라우저 로컬 파일 열기 정책으로 자동 시각 검수는 미완료. SVG XML·내장 이미지·HTML 외부 리소스 미사용은 검사했습니다.

다음 단계: 사용자 시안 검토 후 Remotion 템플릿 및 5~10초 샘플. 현재 시안은 정지 화면이며 동영상은 아직 없습니다.
